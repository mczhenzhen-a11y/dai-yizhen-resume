## 二、JD 要素提取

### 工作职责

1. **参与集团 To C**（会员 APP / 小程序 / 全域会员系统）与 **To B**（门店运营系统 / 供应链系统 / BI 看板）产品的**需求调研、方案设计与迭代优化**；
2. **深入门店一线与用户场景，挖掘真实需求**，输出**产品需求文档（PRD）、原型设计与用户故事**；
3. 协同**研发、设计、运营**团队推进产品开发全流程，把控**项目进度与交付质量**；
4. 基于数据指标（**转化率、留存率、GMV、NPS** 等）进行**产品效果分析**，持续驱动产品优化；
5. 关注行业**竞品与零售数字化趋势**，输出**竞品分析与产品创新建议**。

### 任职资格

1. **2027 届本科及以上**，专业不限，计算机、信息管理、统计学、市场营销、**工业设计**等相关专业优先；
2. 对产品工作有强烈兴趣，具备优秀的**逻辑思维、用户同理心**和**结构化表达能力**；
3. 有产品相关实习经历、独立完成过**产品原型/需求文档**、或有**校园产品项目经验**者优先；
4. 熟练使用 **Axure / Figma / 墨刀** 等原型工具及 **Office 套件**，具备**基础数据分析能力**；
5. 自驱力强，能承受快节奏，具备良好的**跨部门沟通与项目推进能力**。

### 隐性要求

- **2027 届精确命中**（你 2026.09 升大四，2027.06 毕业）→ **无资格风险**
- 专业列表明确含"工业设计"→ **白名单命中**（专业不限，则进一步加分）
- "深入门店一线 + 零售数字化" → 看重**线下/真实场景调研能力**与**电商/供应链业务认知**，而非纯互联网产品
- ToB + ToC 双线 → 需同时具备"C 端用户体验"与"B 端业务流程"两类产品能力

## 四、匹配度评估：约 74%（设计背景切入零售数字化产品，强）

**核心叙事王牌——你可能是候选池里唯一"设计 + 电商落地"双背景的人：**

1. **ToB 供应链落地王牌（融水实习首次在 PM 语境下启用）**：多数校招产品候选人有 C 端项目但**几乎没有真实供应链/电商落地经验**。你的融水实习（832 平台运营 + 仓储/物流/业务整合 + 198,000 元订单 + 13% 收益率）是 JD 职责第 1 条 ToB（供应链系统）和 D3（协同研发/运营推进）的直接证据。
2. **ToC 会员产品王牌**：亲子系统（会员式健康服务，leader + 服务蓝图 + 商业画布）、宠芯（移动端 APP 全流程）、AR 导览（出行场景）——对应 JD 职责第 1 条 ToC（会员 APP/小程序/会员系统）。
3. **深入场景调研王牌**：JD 强调"深入门店一线与用户场景"，你有完整的**线下/真实场景调研方法论训练**（观察法/访谈法/角色扮演/问卷调查/用户流程图）——这是面试"你如何挖掘用户真实需求"的有力回答。
4. **2027 届 + 工业设计白名单 + 结构化表达**：专业不限但工业设计优先；交互设计课程完整方法论链路是"结构化表达"的背书。

**主要缺口**（按优先级）：

1. **PRD / 用户故事**——最大缺口。投递前最高优先动作：用亲子系统或宠芯补写 1 份简版 PRD（背景→目标用户→场景→功能列表+优先级→数据指标）加 1 个 user story 示例，放进作品集。
2. **Axure / 墨刀**——JD 明文。Figma 熟练则如实说"同族工具可快速上手"，不虚构；若花 1 天用 Axure 画一个简单原型则是加分。
3. **运营指标（转化率/留存率/GMV/NPS）**——面试前补课概念，能说出"会员产品看什么指标、为什么"即可；不必在简历写实操。
4. **零售行业认知**——建议研究万辰好想来/量贩零食赛道，准备"如果给会员系统做创新，我会怎么切入"的思考（呼应 D5 产品创新建议）。
5. **竞品分析文档**——中等缺口，面试前可用于练习。
