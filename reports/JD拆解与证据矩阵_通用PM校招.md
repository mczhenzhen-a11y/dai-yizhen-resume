| **R4** | 与运营、市场紧密配合，完成产品目标达成，对合作类项目予以支持 | 跨部门协作 + 业务结果导向 | ⭐⭐⭐⭐ |

### 任职资格（5 条 = 5 类人画像）

| 编号 | 原文要点 | 隐含考点 | 权重 |
|------|---------|---------|------|
| **Q1** | 本科以上学历，专业不限 | 学历兜底，专业不看 → 工业设计本科✅无资格风险 | ⭐ |
| **Q2** | 熟悉产品实施全过程：市场分析 / 需求分析 / 功能设计 / 业务流程设计 / 界面设计 / 用户研究 / 可用性测试 | **7 项方法论全覆盖**，全是软基础考察 | ⭐⭐⭐⭐⭐ |
| **Q3** | 逻辑思维 / 学习创新 / 数据分析 / 语言表达 | 4 项通用能力 | ⭐⭐⭐⭐ |

| **Q5** | 责任心 + 上进心 + 团队合作 + 抗压 | 软素质核心 | ⭐⭐⭐⭐⭐ |

### 关键判断

1. **不限行业 / 不限专业**：这是最典型的"通用型 PM 校招模板"，各厂社招/校招都会用。这意味着**没有差异化关键词**——而是考"基本功"的全面性与可迁移性。
2. **R1 + R3 = 项目管理主线**：把"对产品数据负责"和"快速推进功能上线"结合看，JD 在筛选"能交付、能负责"的执行型 PM，不是"思维天马行空但落不了地"的人。
3. **Q2 的 7 项基础方法论是硬性筛选**：候选人对这 7 项至少要说出具体应用案例，否则简历过不了初筛。
4. **Q5 的"抗压""责任心"看似软素质，但放心，HR 会用 STAR 追问**——必须有真实"硬扛过"的案例来背书。

## 四、匹配度评估：约 **72%**

### 强项总览

✅ **"广度 + 执行力 + 文挡输出" = 通用 PM 基础盘三连胜**

1. **项目管理 / 责任心主轴**：融水实习 198000 元订单跨部门交付是这份 JD 里**几乎最稀缺**的"真实商业抗压 + 跨部门推动落地"证据——多数在校候选人拿不出"具体金额 + 具体团队组合 + 具体交付结果"的真实商业落地故事。
2. **产品全周期闭环**：5 个项目全部覆盖"调研 → 需求 → 设计 → 落地"全路径，正好回应 JD R1 的"规划 → 设计 → 制作 → 开发 → 测试 → 上线"。
3. **PRD / 文档输出（候选人有独特弹药）**：已用 PRD 思维做行业分析（10+ 家公司 JD 拆解矩阵 + 系列报告输出），这是其他候选人没有的真实文档行为背书。
4. **设计背景的 PM 差异化**："熟悉界面设计 + 视觉效果把控"在 R2（"易用性负责"）+ Q2（"界面设计"）上是少数 PM 候选人具备的差异化锚点。

### 主要缺口（按优先级）

1. **正式 PRD 文档（最大缺口）**：简历诚实标注【正在系统补】，建议投递前用亲子系统或宠芯项目补写 1 份**8–10 页**简版 PRD（背景 / 目标用户 / 痛点 / 目标 / 功能列表 + 优先级 / 影响面 / 验收标准）。这是反复出现的最大缺口，一次写好可同时装备多个版本。
2. **可用性测试正式经历（中等缺口）**：200 份问卷能间接覆盖，但建议复盘一两次"邀请 5–8 位用户做原型可用性测试"的小型练习（不限项目，亲子系统或宠芯都行），能直接补上。
3. **Axure / XMind（隐性短板）**：JD 没明文要求，但如果考"快速画流程图"会临时抱佛脚，建议花 1–2 天速成（半天够）。
4. **行业经历（中性）**：JD 不限行业，但若投递公司有明确业务方向，建议在自我评价中加入"对该业务的初步理解"作为诚意表达。

## 六、定制策略与版本 Y 关键动作

### 简历顶部"一句话定位"重新设计

**Before**：`电商产品方向 · 2027 届校招`

**After**：`产品经理（校招）· 设计背景 · 2027 届 | 真实 B 端项目落地 + 完整产品全周期训练`

—— 把"电商"剥掉（限定行业），强化"产品全周期 / B 端落地 / 设计 + PM 跨学科"三个非行业性能力锚点。

### 项目顺序调整

- **第一：融水实习**（项目管理 + 跨部门 + B 端电商 + 抗压 + 责任心）
- **第二：亲子系统**（服务蓝图 + 商业模式画布 + 业务流程设计 + leader）
- **第三：宠芯**（C 端全流程 + VOC 数据 + 文档输出）
- **第四：AR 地铁**（需求拆解 + 范围界定 + leader）
- **第五：中控屏**（产品定义）

### 核心能力区重建（5 条全围绕基础盘）

1. 需求收集与分析
2. 产品全周期 / 规划与管理
3. 跨部门协调与推进落地
4. 数据驱动与效果意识
5. 自驱学习与文档输出

### 自我评价重写（3 条精准命中 Q3、Q4、Q5）

## 九、合规与投递策略总评

- **匹配度**：约 72%（中强）
- **可投递范围**：通用 PM 基础盘，可同时投多行业（**互联网、金融、电商、SaaS、教育、出行、医疗**等）的校招 PM 岗 / 产品助理岗
- **作为"通用模板"**：版本 Y 是所有 PM 岗简历的**母版**——后续任何方向都可在此基础上做"行业化微调"而非"重写"
- **建议投递顺序**：先用版本 Y 投递若干**未指定业务方向**的通用 PM 岗试水，验证面试反馈后再针对性调整
