## 三、整体匹配度评估

**约 78%（强）**——这是目前所有 JD 中综合匹配度最高的一类岗位。

### 三张王牌
1. **人机协同闭环**（Q1 核心考点）：宠芯项目"AI 生成→人工审核→审美优化"是完整的人机协同工作流，且"制定视觉规范作为 AI 输出筛选标准"直接回答"对 AI 输出进行高质量判断"——这正是 JD 最独特、多数候选人最缺的能力证明
2. **多模态交互**（D3 核心考点）：智能中控屏的"环境感知+语音+触控+多设备联动"是多模态交互的完整校园版实践
3. **AI 范式认知**（B2）：有真实的自主调研行为（AI 产品设计范式、Agent、RAG 认知），且三个项目都是主动引入 AI 工具，"意愿"有行为背书

### 弱项与缺口
| 缺口 | 严重度 | 应对 |
|------|--------|------|
| 对话式 AI 产品实操（如聊天界面/对话流设计） | 中 | 简历中以语音交互+生成式反馈间接覆盖，不虚构；面试可谈对豆包/元宝等对话产品的观察 |
| AI 完整产品设计案例 | 中 | 用调研认知+设计方法论组合论证迁移能力 |
| 原型环节的 AIGC 提效深度 | 低 | 措辞控制在"AI 辅助高保真页面设计"证据范围内 |
| 作品集链接 | 高（通用） | 所有版本共同缺口，最优先补齐 |

## 四、简历定制策略（版本 O）

### 项目排序与叙事轴
排序逻辑：**人机协同 → 多模态 → 新交互形态 → 综合设计能力 → AI 辅助可视化**

1. **宠芯 UI 设计**（第一）：按"AIGC 提效 + 人机协同"重新展开——AI 参与设计探索（灵感发散）、视觉方案生成（素材）、AI 输出判断（规范约束筛选），把"AI 生成→人工审核→审美优化"流程作为叙事主线
2. **全屋家居智能中控屏**（第二）：主打"多模态交互"——环境感知+语音+触控+多设备联动，直接回应 D3
3. **中国城市虚拟交互系统设计 AR 地铁导览**（第三）：新交互形态（AR 生成式内容反馈）+ 第一负责人 + Prompt 优化
4. **亲子体重管理系统**（第四）：用研+服务蓝图（用户触点）+ leader + 商业模式画布，回应 D1"体系化分析洞察用户需求、在用户触点挖掘设计机会"
5. **紫荆花信息可视化**（第五）：ChatGPT 辅助信息架构（AI 拆解复杂问题的直接证据）+ 数据与图形可视化专业能力（Q2 列出的专业方向）

### 核心能力模块重构（六维度）
1. **人机协同工作流**（JD 原词"人机协同的工作意识和习惯"）
2. **AIGC 提效应用**（设计探索 / 视觉方案生成 / Prompt 迭代）
3. **多模态与新交互形态**（语音 / 触控 / 环境感知 / AR 生成式反馈）
4. **用户研究与需求洞察**（问卷 200 份有效 / 用户画像 / 服务蓝图触点）
5. **交互设计全流程**（调研→模型→架构→流程→评估）
6. **视觉设计与信息可视化**（规范体系 / 3 个已发布作品）

### 关键词融入位置
- "对 AI 的输出进行高质量判断" → 核心能力第 1 条，用宠芯规范筛选实例支撑
- "拆解复杂问题" → 紫荆花信息架构 + 交互设计方法论
- "对话式、生成式、多模态" → 核心能力第 3 条，逐一有项目对应
- "AI 产品的设计范式" → 补充说明的兴趣表达（基于真实调研）
