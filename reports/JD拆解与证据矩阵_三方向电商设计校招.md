## 六、三方向匹配度对比与推荐

| 维度 | 方向一 交互设计 | 方向二 UI 设计 | 方向三 创意视觉 |

| **专业匹配** | 🟢 工业设计优先 | 🟢 工业设计优先 | — 无限制 |

| **商业思维** | 🟢 商业模式画布 | 🟡 间接 | 🔴 无直接证据 |

| **业务增长指标** | 🟡 电商平台实践 | 🔴 无 | 🔴 无 |
| **leader 经验** | 🟢 两次 | 🟢 两次 | 🟢 两次 |
| **已发布作品** | 🟡 3 个 | 🟡 3 个 | 🟢 3 个 |
| **整体匹配** | **★★★★★ 强** | **★★★★ 中偏强** | **★★★ 中** |

### 推荐：方向一（交互设计）为主投方向

**理由：**
1. **专业直接命中**：JD 方向一明确"工业设计优先"，你的专业完全对口
2. **方法论闭环**：交互设计基础课程提供了"调研→建模→架构→流程→方案→评估"的完整证据链
3. **用户研究深度**：200 份问卷+用户流程图分析+用户画像，直接命中"调研和分析能力"
4. **商业思维**：商业模式画布是正儿八经的商业化思考证据，直接命中"商业设计思路"
5. **leader 经验**：两次项目第一负责人，直接命中"执行力强、沟通协调、快速推进方案落地"
6. **缺口可控**：3 个中级缺口（活动玩法、功能数据复盘、交互文档标准化）可通过面试准备和作品集整理补强

### 方向二作为备选

如果你的作品集中 UI 视觉作品更强，方向二也是可行选择。核心策略：在方向一简历基础上强化"页面风格定调+视觉规范"维度即可。

### 方向三不建议主投

核心缺口（点击率/转化率业务指标）无法通过课程作品覆盖，硬投会暴露短板。

## 七、改写策略 — 方向一交互设计

### 核心叙事线

JD 方向一的四条职责对应四条叙事线：

| JD 职责 | 叙事线 | 对应项目 |

| D3 数据分析复盘+迭代 | "数据驱动的设计验证与迭代" | 宠芯（200 份问卷验证）+ 亲子（用户反馈持续优化）+ AR（流程图分析机会点） |
| D4 自驱想法和需求 | "主动发现问题并提出创新方案" | AR（自主提出概念）+ 亲子（自主规划商业画布）+ 交互设计基础（自主选题） |

### 关键改写决策

1. **求职意向**：交互设计师 · 2027 届校招
2. **技能模块**：以"交互设计方法论"为核心，突出"体系化设计思路""调研分析能力""商业设计思路"
3. **项目排序**：AR 地铁（D1+D2+D4 全命中+leader）→ 亲子系统（D2 商业思维+leader）→ 宠芯（D3 数据验证）→ 交互设计基础（Q1 方法论）→ 智能中控屏（D1 跨端）
4. **电商业务关联**：实践经历（832 电商平台）提到更显著位置，强化"理解电商业务场景"的证据
5. **JD 关键词自然融入**：业务增长、用户体验、场景分析、交互方案、功能数据、用户反馈、迭代思路、自驱想法、调研结论、商业设计思路——均基于真实项目事实融入，不堆砌
