## 三、定制策略（版本 N）

游戏 UI 岗的画像 = **UI/图标/控件硬功夫 + 规范体系 + 3D/AIGC 加分 + 游戏热情**。定制要点：

1. **求职意向改为"游戏 UI 设计师"**，信息行突出作品集（游戏 UI 改造练习是关键动作，见下）。
2. **项目排序以"UI 视觉硬功夫 + 规范体系"为轴**：
   - 宠芯第一位（UI/图标/控件 + 视觉规范体系 + AIGC——一项目命中 JD 四条职责）
   - 智能中控屏第二（UI + 3D 渲染 + 软硬件视觉一体化）
   - 新能源 3D 动态交互网站第三（3D 视觉 + 动态交互——直接对应加分项 2）
   - 洛阳宫灯动态可视化第四（动态视觉 + 审美 + 已发布）
   - AR 地铁导览第五（虚拟交互 + 游戏化交互逻辑——AR 扫描触发与游戏交互设计相通，且有 AIGC 探索）
3. **核心能力区直接呼应 JD 用词**：UI/图标/控件设计 → 设计规范与视觉风格标准体系 → 美术功底与审美 → 3D 设计能力（加分项前置）→ AIGC 多形态创意工具 → 跨职能协作。
4. **补充说明新增"游戏热情与作品集改造计划"**：真诚表达游戏兴趣（具体游戏 + 对其 UI 的观察），并说明作品集正在补充游戏 UI 练习。
5. 832 实践经历保留——"跨职能协作推动落地"的可迁移证据。
