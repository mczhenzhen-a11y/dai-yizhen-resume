## 一、基于亲子协同的肥胖儿童体重管理服务系统（2026.03 – 2026.06 · 项目第一负责人，4–5 人组）

**做了什么**：主导前期用户调研（观察法 / 访谈法 / 角色扮演 / 问卷），梳理亲子群体痛点；横向调研同类产品完成竞品分析；独立撰写 PRD；绘制服务蓝图与商业模式画布；设计 Web 端服务平台（Figma）与居家教练随身设备（Rhino + KeyShot）；协调组内分工按期交付。

**获取成果（产出物）**：
- 用户画像与服务机会点报告 1 份
- 竞品分析结论 1 份（同类儿童健康产品功能 / 干预方式 / 商业模式对标）
- 项目 PRD 1 份（背景 → 用户场景 → 竞品结论 → P0/P1/P2 需求 → 业务流程 → 界面说明 → 验收标准）
- 服务蓝图 + 商业模式画布各 1 份
- Web 端高保真方案 + 智能硬件设备方案（软硬件一体）

**获得的能力关键词**：`用户研究` `需求分析` `竞品分析` `PRD 撰写` `服务蓝图` `商业模式画布` `功能优先级排序` `团队管理` `项目进度把控` `跨职能协作` `软硬件一体设计`

## 附录：6 个项目的一波三折设计过程（2026-10-10 增补）

> 完整叙事见 `项目经历_一波三折设计过程.md`。这里只给"卡点 → 调整 → 跑通"三句话版，方便插入简历或面试引用。

| 项目 | 第一版方案 | 卡点 | 怎么破局 | 最终跑通 |
|------|------|------|------|------|
| **亲子系统** | 问卷派（300 家长 + 100 儿童） | 家长孩子诉求错位，对不上话 | 换**角色扮演 + 入户观察** | 挖出"亲子协同"切入点 |
| **宠芯 APP** | 健康监测为核心卖点 | 真实痛点不在健康数据上 | 改问卷题目"暴露需求"→ 扩发 200 份 | 定位从"健康监测"转"安全守护" |
| **AR 地铁导览** | AR 实时路径叠加 | 信号差、定位漂移，体验崩溃 | AR 用在"地标文化导览"上 | **主推文化导览 + 兜底站厅识别卡** |
| **智能中控屏** | 全屋 30+ 设备总指挥 | 用户只用 5–7 个，记不住 30 个 | "大而全" 缩到"玄关场景" | "墙面中控"替代 6 个开关和遥控器 |
| **升降桌** | 套用国外标准人机工程学 | 中国家庭场景套不上 | 转**行为模式 + 健康风险** | 从"促站立"转"降低站立阻力" |
| **握力圈** | 医疗器械造型 | 用户不愿让家人看到"像医院" | 转"**去器械感的家居器具**" | 圆润外壳 + 家居配色，使用频次翻倍 |

### 6 段"一波三折"能力关键词（提炼版）

| 项目 | 一波三折能力关键词 |
|------|------|
| 亲子系统 | **方法适配判断** + **被数据打脸时换方法** + **真实场景 > 自述诉求** |
| 宠芯 APP | **不被"应该有什么"绑死** + **题目设计决定结论** + **用户要什么做什么** |
| AR 地铁 | **新技术 ≠ 解决新问题** + **demo 阶段就要卡一次** + **主推 + 兜底架构** |
| 智能中控屏 | **小而准 > 大而全** + **切入高密度场景** + **跑通再外溢** |
| 升降桌 | **数据真实 ≠ 场景真实** + **行为 > 标准** + **降低阻力 > 促进行为** |
| 握力圈 | **产品形态在传递信号** + **去器械感 / 去工具感** + **真实家庭研究更可靠** |

### 简历嵌入示范（以宠芯 APP 为例）

**扩写前（5 行）**：
- 围绕宠物主"健康 + 位置追踪"需求发放问卷 230+ 份 / 有效 200 份
- 调研同类产品输出竞品对比结论
- 独立撰写 APP 产品 PRD
- 完成信息架构、交互流程与移动端高保真方案
- 产出物：200 份问卷分析报告、竞品对比、产品 PRD、视觉规范

**扩写后（8 行）**：
- **第一版走偏**：把"健康监测"（体温 / 心率 / 呼吸 / 活动量）做核心卖点，**小样本问卷暴露**——宠物走失、独自在家焦虑、老龄宠物不会表达这些真实痛点都没在第一版功能里
- **调整方法**：把调研题目从"对功能感兴趣程度"改成"实际生活中最焦虑什么"——前者评估产品，后者暴露需求
- **核心定位调整**：从"**健康监测 App**"转向"**宠物安全守护 App**"——走失定位 / 独自在家动态 / 老龄健康档案排前三，健康监测降为辅助
- 扩发问卷到 230+ 份 / 有效 200 份，Excel + SQL 独立做数据清洗
- 竞品对比 + PRD（含功能优先级与数据指标）+ 信息架构 + 交互流程 + 高保真方案 + 视觉规范
- **设计过程能力**：调研题目设计会决定结论，"我以为"和"用户要"是两套题目——这是设计过程里学到的最值钱的一课
