## 首选项目：宠芯 UI 设计 — AI 辅助宠物健康管理 APP（个人项目，2025.04 – 2025.06）

### 完整版（约 600 字，适合申请表长文本框）

**一、项目目标与背景**

随着宠物家庭化趋势加深，宠物主对宠物健康状态与位置信息的实时追踪需求日益突出。本项目为宠物智能项圈设计配套 APP，目标是独立完成从用户调研、信息架构到高保真界面的完整 UI 设计方案，并在有限的项目周期内探索 AIGC 工具与设计师协作的高效工作范式。

**二、AI 工具及模型的选择与原因**

我按"任务类型匹配工具模态"的原则选型：**文本与结构类任务**（需求梳理、信息架构发散、界面文案思路）使用 ChatGPT，因为对话模型在结构化梳理和快速发散上效率最高，适合设计前期的"想清楚"阶段；**视觉类任务**（风格探索、视觉素材、Banner 素材初稿）使用 AIGC 图像生成工具【请本人确认具体生图工具名称，如即梦 / Midjourney / SD 等】，用于快速产出大量风格候选，缩短视觉探索周期。选型的核心逻辑是：让 AI 承担"量大但决策权重低"的发散性工作，把我的时间留给调研、判断与精修。

**三、我与 AI 的分工**

- **AI 负责**：设计灵感发散、信息架构候选方案、视觉素材批量生成、通过 Prompt 迭代产出风格变体；
- **我负责**：用户调研与需求定义、AI 产出的审美审核与筛选、信息架构的最终决策、图标风格 / 配色 / 字体层级视觉规范的制定、Figma 高保真界面排版与交互流程设计、问卷验证与迭代。
- **协作原则**：AI 是产能放大器，审美判断和设计决策权始终在人——我逐步沉淀出"AI 生成 → 人工审核 → 审美优化"的稳定流程。

**四、核心挑战及解决方案**

1. **AI 生成素材风格不一致，与产品调性偏离。** 解决：先制定图标风格、配色体系与字体层级规范，以此为筛选硬标准，并把风格约束词写入 Prompt，AI 产出经筛选后由我在 Photoshop / Illustrator 中二次精修，保证最终视觉统一。
2. **AI 给出的信息架构建议偏泛化，与真实用户需求优先级不匹配。** 解决：用数据校准——发放设计评估问卷 230+ 份、回收有效问卷 200 份，基于数据分析验证界面可行性与核心功能优先级，再用调研结论反向修正 AI 方案。
3. **Prompt 产出质量不稳定。** 解决：持续迭代 Prompt 表述方式，逐步固化出适配该项目风格的高质量 Prompt 写法【请本人确认，如有 Prompt 示例可在作品集中展示】。

**五、项目结果**

- 交付宠物健康管理 APP 完整移动端高保真界面方案，覆盖核心页面交互与视觉设计；
- 沉淀完整的视觉规范文档（图标风格规范、配色方案体系、字体层级标准），并应用于 Banner 运营图等实际产出；
- 200 份有效问卷验证了界面可行性与功能优先级，实现数据驱动的决策闭环；
- 形成"AI 生成 → 人工审核 → 审美优化"的可复用人机协作流程，可直接迁移到后续工作中的视觉设计任务。

### 精简版（约 150 字，适合字数受限的表单）

> 宠芯是为宠物智能项圈设计的配套健康管理 APP（个人项目）。按任务模态选型：结构与文案类任务用 ChatGPT 做需求梳理与信息架构发散，视觉类任务用 AIGC 图像工具做风格探索与素材生成。分工上 AI 负责"量大、决策权重低"的发散工作，我负责调研定义、审美审核、视觉规范制定与 Figma 高保真精修。核心挑战是 AI 素材风格不一致与架构建议泛化，我以自建视觉规范约束 Prompt、并用 230+ 份问卷（有效 200 份）的数据校准优先级。最终交付完整高保真方案与视觉规范文档，并沉淀出"AI 生成 → 人工审核 → 审美优化"的可复用协作流程。

## 备选项目：中国城市虚拟交互系统设计 — 城市地铁 AR 导览（第一负责人，2026.04 – 2026.06）

> 适用场景：如果岗位更看重"项目负责人角色"或"AR/新兴交互"，用这个项目作答；五个维度结构相同

**一、目标背景**：作为第一负责人，设计基于 AR 的城市地铁虚拟交互服务，构建"AR 空间导航 + AR 文化导览"双场景交互框架，探索虚拟交互技术在真实城市出行场景中的体验落地。

**二、AI 工具选择及原因**：选用 ChatGPT / AIGC 工具辅助灵感发散与素材生成——前期概念发散阶段需要大量方案候选，AI 能显著压缩探索周期；同时通过 Prompt 优化让产出持续逼近设计目标。

**三、分工**：AI 负责灵感发散、视觉素材生成与 Prompt 迭代；我作为负责人把控全流程——用户调研与功能优先级决策（问卷调查 + 用户流程图分析）、双场景交互框架设计、信息架构、Figma 高保真设计稿与最终方案把关。

**四、核心挑战及解决方案**：AR 交互无成熟范式可循，方案容易发散失焦——解决方式是用问卷调查与用户流程图分析驱动功能优先级排序，先收敛核心场景再扩展；AIGC 素材与 AR 场景调性匹配度不稳定——通过持续 Prompt 优化提升产出与设计目标的匹配度。

**五、项目结果**：交付双场景 AR 导览服务的完整高保真设计方案，形成"调研 → 交互框架 → 高保真"的完整链路，并验证了 AIGC 在虚拟交互概念设计阶段的提效价值。
