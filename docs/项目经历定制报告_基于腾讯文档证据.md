## 三、版本 A：百度 UI/AI 视觉设计 — 项目经历

**JD 核心关键词**：UI 设计、动效设计、图标设计、Web 端/移动端、Figma、PS、AI、AI 辅助设计、用户体验、竞品分析

**选项目逻辑**：突出 AI 辅助设计能力 + 移动端/Web 端 UI + 视觉产出

```markdown
## 项目经历

### 宠芯 UI 设计 — AI 辅助宠物健康管理 APP（个人项目）
**项目角色**：UI / AI 视觉设计师 &nbsp;&nbsp; **周期**：2025.04 – 2025.06

- 聚焦宠物主追踪宠物健康与位置的需求，独立完成宠物智能项圈配套 APP 的 UI 设计，覆盖核心页面交互与视觉方案。
- **结合 ChatGPT / AIGC 辅助完成高保真页面设计**：利用 AI 工具进行设计灵感发散、视觉素材生成与 prompt 优化，提升设计产出效率，产出移动端完整界面方案。
- 开展用户研究：发放设计评估问卷 230+ 份，回收有效问卷 200 份，基于数据分析验证界面可行性与核心功能优先级。
- 构建 APP 信息架构与核心交互流程，完成 Banner 运营图设计与图标视觉规范梳理，强化产品视觉识别一致性。
- 使用工具：Figma、Photoshop、Illustrator、ChatGPT

### 新能源企业 3D 动态交互网站设计
**项目角色**：UI / 交互设计师 &nbsp;&nbsp; **周期**：2025 学年

- 设计新能源企业 3D 动态交互网站，首页场景规划七个核心版块，融合 3D 视觉与交互体验，展示 Web 端 UI 设计能力。
- 完成页面信息架构与交互流程设计，结合动态视觉效果提升用户浏览体验。
- 作品已发布小红书，可提供在线预览链接。
- 使用工具：Figma、【待本人补充：如 Spline / Webflow / 其他 3D 交互工具】

### 全屋家居智能中控屏 UI 设计
**项目角色**：UI 设计师 &nbsp;&nbsp; **周期**：2025 学年

- 以玄关空间为切入点，设计墙面中控终端的 UI 界面，重点聚焦智能照明系统的交互体验。
- 引入环境感知、语音交互及多设备联动的交互逻辑，探索符合真实生活节奏的智能家居控制方式。

- 使用工具：Figma、KeyShot
```
