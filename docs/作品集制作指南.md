# 作品集制作指南

> 针对：戴易臻 | 工业设计背景 | 投递 UI/UX 设计实习 + 工业设计实习
> 目标：1-2 天内产出可用的作品集链接，满足所有投递版本需求

---

## 一、推荐方案：双链接策略

不要只放一个链接。**站酷 + Figma 双链接**是性价比最高的组合：

| 链接 | 定位 | 展示什么 | 放在哪版简历 |
|------|------|---------|------------|
| **站酷主页** | 作品集总入口 | 所有作品的图文展示页，HR 浏览体验最好 | 所有版本 |
| **Figma 发布链接** | 交互原型展示 | 可点击操作的高保真原型，证明你会用 Figma | 版本 A/B/D（UI 方向） |

站酷链接放简历最前面，Figma 链接放在对应项目描述里作为"查看原型"入口。

## 二、站酷发布步骤（主链接）

### 第 1 步：注册与认证

1. 打开 [zcool.com.cn](https://www.zcool.com.cn)
2. 用手机号注册账号
3. 完善个人资料：
   - 昵称：建议用真名或设计笔名（如"戴易臻"）
   - 头像：用专业照片或设计感头像
   - 一句话简介：如"工业设计在读 · UI/UX 设计方向 · Figma / Rhino / KeyShot"
   - 职业身份：学生 / 实习求职中

### 第 2 步：发布作品（每个项目一篇）

每个项目单独发布一篇文章，不要把所有作品塞进一篇。站酷发布流程：

1. 点击右上角「发布作品」
2. 选择「文章」类型
3. 填写标题：格式建议 `[项目类型] 项目名称 - 你的角色`
   - 例：`[移动端 APP 设计] 母婴社区电商 APP — 用户研究到高保真原型`
4. 上传封面图：选项目中最有视觉冲击力的一张（750×400px 以上）
5. 正文按以下结构组织：

```
## 项目背景
- 项目名称 / 时间 / 你的角色
- 解决什么问题 / 面向什么用户

## 设计过程
1. 用户研究：问卷设计 → 数据回收 → 需求提炼
   [插入调研截图 / 数据图表]
2. 竞品分析：对比了哪些产品，发现了什么机会
   [插入竞品分析图]
3. 信息架构：梳理了哪些功能模块
   [插入信息架构图 / 思维导图]
4. 交互流程：核心任务的操作路径
   [插入流程图]
5. 高保真 UI：最终界面设计
   [插入界面截图，3-5 张核心页面]

## 设计成果
- 量化结果（如问卷回收 200 份、设计落地后订单额等）
- 个人收获与反思

## 使用工具
Figma / Photoshop / Illustrator 等
```

6. 标签：添加 `UI设计`、`APP设计`、`用户体验`、`交互设计`、`工业设计` 等标签
7. 发布后获取链接，格式为 `https://www.zcool.com.cn/work/xxxxx`

### 第 3 步：整理主页

发布 2-3 篇后，你的站酷主页地址 `https://www.zcool.com.cn/u/你的ID` 就是作品集总链接。

把主页链接放在简历的**联系方式区域**，标注"作品集"。

## 三、Figma 发布链接步骤（交互原型展示）

你已经在用 Figma，这一步最快：

### 第 1 步：整理原型文件

1. 打开你的项目 Figma 文件
2. 确保原型有可交互的 Frame（设置了 Prototype 连线）
3. 整理页面结构：
   - Page 1：Cover（封面页，写项目名称和简介）
   - Page 2：Process（设计过程，放调研截图、流程图等）
   - Page 3：UI Screens（最终界面，按流程排列）
   - Page 4：Prototype（可交互的原型入口）

### 第 2 步：发布为公开链接

1. 点击左上角 Figma 菜单 → `Share`
2. 权限设置为 `Anyone with the link can view`
3. 勾选 `Allow prototype previews`（允许原型预览）
4. 复制链接

### 第 3 步：验证链接

用无痕窗口打开链接，确认：
- 能看到所有页面内容
- 能点击进入原型预览
- 加载速度可接受

> **如果 Figma 国内加载太慢**：把文件导入「即时设计」（js.design），操作完全一样，发布后链接国内秒开。

## 五、分版本作品集策略

你有 4 个简历版本，作品集不需要做 4 份，但主页排序可以调整：

| 简历版本 | 投递方向 | 作品集排序 | 链接策略 |
|---------|---------|-----------|---------|
| **版本 A** 百度 UI/AI 视觉 | UI + AIGC | 作品 1 → 2 → 4 → 3 | 站酷主页 + Figma 原型链接 |
| **版本 B** 阿里体验设计 | 全链路 UX | 作品 1 → 2 → 3 → 4 | 站酷主页 + Figma 原型链接 |
| **版本 C** 工业产品设计 | 产品设计 | 作品 3 → 1 → 2 | 站酷主页（工业设计置顶） |
| **版本 D** 视觉设计 | 图标/视觉 | 作品 4 → 1 → 2 → 3 | 站酷主页 + Figma 链接 |

**站酷支持调整作品排序**：进入主页管理 → 拖拽调整顺序。投不同方向时花 1 分钟调一下排序即可。

## 六、作品呈现技巧

### 界面展示

- **不要只放成品截图**：每个页面配上简短的设计说明（为什么这么设计）
- **用 Mockup 包装**：把 APP 界面放进手机外壳模板，比裸截图专业 10 倍
- **展示设计系统**：整理一页色彩规范 + 字体规范 + 组件库，体现规范性
- **标注关键决策**：在截图上用箭头标注"这里为什么这么设计"

### 图文排版

- 每篇作品控制在 **8-15 张图**，太多让人看不下去
- 图片宽度统一，不要忽大忽小
- 文字精简，每段不超过 3 行
- 用分隔线区分不同阶段

### 工业设计作品特殊处理

- 先放 **渲染效果图**（最吸引眼球）
- 再放 **建模过程截图**（证明你会 Rhino）
- 最后放 **设计说明**（产品定位 / 目标用户 / 材料工艺）
- 如果有实物模型照片，一定要放

## 八、简历中怎么放链接

填入简历时用这个格式：

```

原型演示：https://www.figma.com/proto/xxxxx（母婴电商APP高保真原型）
```

或者更简洁：


如果投递的是在线表单（如百度/阿里校招系统），把站酷链接填在"作品集链接"字段，Figma 链接可以在简历 PDF 中作为项目补充说明。

## 九、常见问题

**Q：没有作品怎么办？**
你已经有 2 个项目经历（母婴 APP、Web 平台）和工业设计课程作业，素材是够的。关键是把已有内容整理成结构化的展示。

**Q：作品不够"高级"怎么办？**
不需要每个作品都是获奖级别。HR 看的是你的设计思维和基本功——调研是否扎实、流程是否完整、界面是否干净。把过程讲清楚比炫技更重要。

**Q：站酷和 Figma 哪个更重要？**
站酷。因为国内 HR 打开站酷的体验最稳定，且能一次性看完所有作品。Figma 链接是加分项，证明你真的会用工具做交互原型。

**Q：需要做个人网站吗？**
短期不需要。站酷主页已经够用。如果你未来想长期做自由设计师或求职高级岗位，再考虑用 Framer 搭个人网站。

**Q：Behance / Dribbble 要不要传？**
国内访问需要翻墙，HR 打不开等于没放。优先站酷。如果时间充裕可以同步传 Behance，作为国际化展示备选。

**Q：作品集要不要导出 PDF？**
要。把站酷作品页截图整理成一份 PDF（10-15 页），作为邮件附件投递时的备用方案。有些公司要求直接发 PDF 作品集。
