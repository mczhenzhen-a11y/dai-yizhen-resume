## 三、关键结论

### 3.1 匹配优势（Top 3）

1. **专业对口**：工业设计专业，主修 UI 设计、视觉设计基础、设计调研，与 JD 要求的艺术类专业高度匹配。
2. **项目经验覆盖移动端 UI 与 UX 调研**：拥有「宠芯 UI 设计」和「肥胖儿童体重管理系统」两个完整项目，涉及 APP 高保真设计、用户调研、信息架构、交互流程。
3. **AIGC 工具意识**：职业规划中体现对 ChatGPT / AIGC 的主动使用，可贴合 JD 中"行业新技术趋势"要求。

## 四、修改原则说明

1. **仅基于事实改写**：不对经历、工具、项目成果进行虚构或夸大。
2. **自然融入关键词**：将 JD 中的关键词（UI 设计、用户体验、移动端、Figma、PS、AI 等）融入项目描述，避免生硬堆砌。
3. **缺失信息标注**：对于无法确认的信息（如实习时长、作品集链接、具体工具掌握情况），使用 `【待本人补充】` 标记。
4. **突出设计岗匹配**：将求职意向从"AI 产品设计"调整为"UI/UX 设计实习生"，突出与目标岗位的相关性。
5. **删除/脱敏敏感信息**：保留联系方式，未添加薪资、身份证号等敏感内容。
