### 宠芯 — 宠物智能项圈配套 APP 产品设计（个人项目）

**周期**：2025.04 – 2025.06 &nbsp;&nbsp; **角色**：独立完成

- **第一版走偏（迭代起点）**：立项时把"健康监测"（体温 / 心率 / 呼吸 / 活动量）作为核心卖点——智能项圈听起来就该做这个。**小样本问卷回收后第一个问题就暴露**：宠物走失、独自在家焦虑、老龄宠物不会表达——这些真实痛点都没在第一版功能里。
- **方法调整（破局）**：把调研题目从"对功能感兴趣程度"改成"**实际生活中最焦虑什么**"——前者评估产品，后者暴露需求；扩发问卷到 **230+ 份、回收有效 200 份**，独立完成数据清洗与统计（Excel + SQL 查询），基于结论完成核心功能优先级排序（调查 → 数据 → 决策 → 优先级）。
- **核心定位调整**：从"**健康监测 App**"转向"**宠物安全守护 App**"——宠物走失定位 / 独自在家动态 / 老龄宠物健康档案排前三，健康监测降为辅助功能。
- **竞品分析与 PRD 输出**：调研同类宠物智能硬件与配套 App 的功能结构与运营方式，输出竞品对比结论；独立撰写 APP 产品 PRD（背景 / 用户场景 / 功能列表与优先级 / 交互与界面说明 / 数据指标），并据此推进方案落地。
- **产品全流程文档输出**：独立完成 APP 的**信息架构**、核心**交互流程**与移动端完整高保真方案；制定图标风格、配色方案与字体层级**规范文档**，将判断标准沉淀为可复用的产品视觉规范。
- **AI 工作流**：结合 ChatGPT / AIGC 辅助完成调研梳理、信息结构化与文档撰写，通过 Prompt 迭代与人工校验控制产出质量。
- **设计过程能力沉淀**：调研题目设计会决定结论——"**我以为**"和"**用户要**"是两套题目，这是设计过程里学到的最值钱的一课。
- **获取成果**：产出 200 份问卷数据分析报告、竞品对比结论、APP PRD（含数据指标）与视觉规范文档；获得**数据驱动决策、PRD 撰写与独立完成 C 端产品全流程交付**的产品能力。
