## 项目经历

### 康复握力圈产品设计
**项目角色**：产品设计师 &nbsp;&nbsp; **周期**：2025 学年

- **一波三折**：第一版按"康复器械"思路做，方正造型 + 医用白 + 刻度指示——拿到 5 个康复期用户家里做真实家庭研究时被一致反馈"不想让家人看到这是医疗器械，放在客厅像在医院"。**用户对握力圈的根本需求是"在家随时能拿起来"，不是"被提醒我在做康复"**。
- **调整方向**：从"医疗器械造型"转向"**去器械感的家居器具**"——圆润外壳、家居配色（暖灰 / 燕麦 / 莫兰迪）、一体成型去掉刻度指示，外观像家居摆件。3 个真实家庭连续使用 2 周验证，主动使用频次比第一版明显提升。
- 将握力圈外形新颖、携带便捷、摆放美观的特点与手部形状贴合的工程学设计相结合，完成康复辅助产品的造型设计。
- **用户研究**：运用系统化的观察法、访谈法、角色扮演法、问卷调查法及用户流程图分析，发现用户对握力器使用体验的更高需求——使用时间偏短、倾向在家中或办公放松时锻炼。
- 完成产品调研→产品建模（Rhino）→产品渲染（KeyShot）→展板排版全流程。
- 使用工具：Rhino、KeyShot

### 基于亲子协同的肥胖儿童体重管理服务系统
**项目角色**：项目负责人 / 产品设计师 &nbsp;&nbsp; **周期**：2026.03 – 2026.06

- **一波三折**：第一版用问卷派做法——300 份家长问卷 + 100 份儿童问卷回收后第一个问题就卡住：家长和孩子关注点严重错位（家长关心"长不高"，孩子在意"同学嘲笑"），两份问卷对不上话。**问卷适合"已经知道自己想要什么"的群体，亲子双方各自有另一半真相，问卷只能采到一半**。
- **调整方法**：换成**角色扮演 + 入户观察**——让家长扮演孩子的一天、孩子扮演家长的一天，同步去 3 个家庭做半日观察（晚饭后、睡前、周末写作业）。挖出两个新洞察：①家庭里的体重管理冲突大多发生在晚饭后到睡前这一小时；②家长真正想要的不是"孩子减肥"，是"和孩子一起动起来"的相处场景——**"亲子协同"作为产品切入点的真正来源**。
- 作为项目 leader 主导前期用户调研，梳理目标用户需求与痛点，输出用户画像与服务机会点。
- **设计居家教练随身设备方案**：完成产品造型设计与使用场景定义，使用 Rhino 进行三维建模，KeyShot 进行产品渲染表现，推动从需求到概念方案的落地。
- 规划服务蓝图与商业模式画布，完成整体服务架构设计。
- 负责配套服务平台 UI 设计，实现软硬件体验的一致性。
- 使用工具：Rhino、KeyShot、Figma

### 居家远程办公人群人机工程学设计 — 升降桌
**项目角色**：产品设计师 &nbsp;&nbsp; **周期**：2025 学年

- **一波三折**：第一版按教科书做法——套用国外居家办公人群的标准数据（坐姿 / 站姿 / 桌面高度 / 视距）+ ISO 人机工程学标准。**数据本身没问题，但真实中国家庭场景根本套不上**——家里有小孩、有宠物、有同住的家人、桌面经常堆东西，教科书假设的"理想工作位"在真实家庭里不存在。
- **调整方法**：从"标准答案"转向"**行为模式 + 健康风险**"双线研究——真实观察 5 个居家办公家庭 3 天，记录他们一天里升降桌高度变化的实际次数（多数用户其实懒得动）；同步调研"不站立"的真实原因（桌面太乱、站起来没地方放东西、起身被打断）。**数据真实 ≠ 场景真实，这是第一版跑偏的核心教训**。
- 基于国内外居家办公人群行为模式与健康风险的大量研究分析，聚焦静态坐姿问题与家用工作站的工程学风险。
- **策略升级**：从"**促用户站立**"转向"**降低站立阻力**"——升降桌方案里增加桌面收纳分区、起身时常用的物品固定位、起身动作引导的桌面刻度。不是逼用户站起来，是让站起来这件事变得没那么麻烦。
- 提出结构与行为相结合的设计策略，完成升降桌产品的人机工程学设计。
- 【待本人补充：可补充具体设计方案细节、材料工艺选择、CMF 方案等】

### 全屋家居智能中控屏产品设计
**项目角色**：产品设计师 &nbsp;&nbsp; **周期**：2025 学年

- **一波三折**：第一版想做"能控 30+ 种智能家居设备的中控屏"——家庭设备的"总指挥"，听起来很有想象空间。去 3 个真实家庭做用户研究时第一个问题就暴露：**用户根本记不住 30 个入口，日常实际只控 5–7 个**（门锁 / 主灯 / 空调 / 扫地机 / 窗帘 / 热水器 / 摄像头），其余 20 多个功能"装上去就用过一次"。**"大而全"在真实家庭里跑不通**。
- **调整策略**：从"全屋"缩到"**玄关**"——玄关是家庭最容易被多个设备密集触达的场景（门锁 + 主灯 + 空调 + 扫地机 + 摄像头 + 智能音箱都在这儿）。"小而准"比"大而全"更值得做，尤其 ToC 智能硬件第一版功能越克制越容易跑通。
- **产品形态定位**："墙面中控终端"的真正价值是**在玄关这一个高密度场景里替代 6 个开关和遥控器**——先把玄关做到极致，再外溢到客厅 / 卧室。
- 以玄关空间为切入点，设计墙面中控终端的产品造型，作为家庭智能系统的物理交互载体。
- 重点聚焦智能照明系统，通过与环境感知、语音交互及多设备联动的结合，探索符合真实生活节奏的智能家居控制方式。
- 完成独立的房间调研、用户调研、产品渲染与 UI 界面设计，实现软硬件一体化产品设计。
- 使用工具：Rhino、KeyShot、Figma
