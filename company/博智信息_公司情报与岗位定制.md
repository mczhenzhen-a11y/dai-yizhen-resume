## 一、先确认：是哪家「博智信息」

带"博智"的公司不止一家，但结合你给的 JD（专业不限 / 接受出差 / 热爱互联网 IT 行业 / 需求调研 + 竞品分析），最吻合的是：

**成都博智维讯信息技术股份有限公司（简称：博智 / BOZHI，证券代码 870739）**

判断依据：博智在 BOSS 直聘发布的「初级 CRM 产品经理（应届）」岗位职责几乎逐条对应你这份 JD——"客户需求收集 / 市场调研 / 产品解决方案 / 产品生命周期文档 / 项目周期和进度把控 / 可以接受出差 / 专业不限"。你这份 JD 是它的**产品岗（偏初级/校招）**变体。

**你投的这份 JD 的画像**：上面这份 JD 的职责要求写得很"基础盘"（专业不限、善于学习、归纳总结、逻辑沟通、吃苦耐劳、接受出差、热爱互联网 IT）——这是**B 端产品经理的入门岗**，公司赌的是"学习能力和吃苦耐劳"，而不是现成的行业经验。**这对没有 ToB 软件经验的应届生是友好的**。

**工作内容实况（从公开 JD 反推）**：
1. **跑客户**：去客户现场（酒厂、快消、制造企业）收集需求——这就是"可以接受出差"的真实含义，B 端产品经理大量时间在客户现场和驻场
2. **写方案写文档**：需求分析 → 产品解决方案 → PRD / 需求文档 → 用户使用手册
3. **盯开发**：把功能需求提交开发，跟进度、跟质量、跟上线
4. **看竞品**：盯友商 CRM / 营销 SaaS 动态，总结后落进自己产品

## 六、缺口与补救（诚实标注，不虚构）

1. **🔴 CRM / SaaS / ToB 软件产品经验为零**——这是最大缺口，但 JD"专业不限 + 善于学习"说明公司接受白纸。**面试答法**：融水 832 平台本质就是"给商家用的 B 端系统"（商家入驻、商品管理、订单履约），你做过它的运营侧；把"平台规则怎么影响商家行为"的观察讲出来，就是 B 端产品 sense。
2. **🟡 Axure / 墨刀未证实掌握**——初级岗 JD 明文要求。**投递前动作**：花 1–2 天用 Axure 画一遍宠芯或中控屏的原型（你有 Figma 基础，迁移成本低），简历可从"正在补具"升级为"已上手"。目前版本 AC 如实标注。
3. **🟡 酒类 / 快消 / 制造行业知识无**——博智客户集中在这几行。**投递前动作**：了解一两个案例（如"五粮液的经销商管理难点"），面试提到即加分。不装懂。
4. **💡 加分动作**：做一份**《快消行业 CRM 产品竞品扫描》**小报告——挑 2–3 个知名 CRM/营销 SaaS（销售易、纷享销客、有赞连锁任选），各列核心模块、目标行业、差异点，最后一页写"如果给酒企做经销商管理，我会关注什么"。这份文档直接证明 JD 第 4 条"竞品分析总结并运用于产品"。

## 七、面试高频追问预备

- **"你做过 B 端产品吗？"** → 不装。答：校园项目是 C 端为主，但融水实习天天在"商家（客户）— 平台（系统）— 履约（业务）"之间对需求，这是 B 端的微观版本；加上 5 份 PRD 的文档功底，B 端产品经理的"调研—写文档—盯落地"三件事我都干过小号版本。
- **"能接受出差是什么理解？"** → 去客户现场听需求、驻场陪实施——这正是我想要的：开阔视野、见真实业务。融水实习就是在县域市场跑出来的，我不怕跑。
- **"你一个工业设计的为什么做产品？"** → 设计科班训练的就是"用户调研 → 需求定义 → 方案落地"这条链，只是交付物从造型换成了产品方案；而且我比多数 PM 候选人多一手"画得出来"（Figma/XMind 原型与流程图）。
- **"怎么把竞品分析用到产品里？"** → 举宠芯例子：竞品功能矩阵 + 问卷数据 → 砍掉低优先级功能、聚焦核心场景——"分析总结并运用于产品"我做过完整闭环。
