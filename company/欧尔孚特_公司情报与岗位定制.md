## 二、这家公司怎么做事的（面试时最该懂的部分）

这是**比岗位职责更重要的一层**——欧尔孚特的做事方式，恰好和你简历里的能力是同一种语言。

**1. 文化内核：刨根问底**
官网页脚把"**刨根问底**"列在价值观第一位（其余为：客户第一、高效行动、开放、持续学习）。CEO 的原话是"跨境电商让我们能**直接连接消费者，更精准洞察需求**"。这意味着面试官会反复考察一件事：**你遇到问题，是拍脑袋，还是会去挖到根？**

**2. 选品方法论：调研驱动，不是跟风抄款**
它不盲目跟 BS 榜爆款，而是**扒目标市场用户的真实评论、退货原因、尺寸偏好，再反推产品定义**。
- 同一个斗柜，美国版要做**大规格 + 美式红蓝色调**，日本版要做**小尺寸 + 高收纳 + 冷淡简约**——两个市场两套产品，背后是用户画像拆到了"居住面积 + 审美 + 收纳习惯"的颗粒度。

**3. 供应链是底气：自有工厂 = 成本与速度自主**
两家自有工厂意味着：品控能掐在源头、成本结构自己说了算、改结构到出样不用等外协排期。所以它敢"多款 + 持续上新"。

**4. 合规即护城河**
产品按 **FDA、UL、Prop65、FSC** 等标准设计，多款拿到亚马逊气候承诺友好认证；跨境还要过 **CE / FCC**。它把认证当成品牌基建——这是白牌做不到的门槛。

**5. 从"卖货"到"做品牌"**
先海外注册商标确权，再用品牌词 + 展示型广告沉淀认知，不全押单一渠道。

## 四、为什么你特别对口 Orford（6 个同频点）

这是这份简历真正的差异化逻辑——不是"我什么都能干"，而是"**我和你们用的是同一种方法**"。

1. **专业与工具直接命中**：工业设计（优先专业）+ **Rhino 熟练**——Orford 高级工业设计师岗明文要求"软件：犀牛"，你已能熟练建模渲染。
2. **家居 / 家具品类有真实项目（3 个）**：**升降桌**项目（居家办公人机工程学家具）直接对口 **DEVAISE 的升降桌 / 办公家具**；**全屋智能中控屏**对口智能家居场景；**康复握力圈**（去器械感的家用器具）对口 WLIVE 的居家收纳 / 家用小件逻辑；宠物项圈、亲子设备也是"实体产品 + 软件"的软硬一体思路——和家居产品开发同构。
3. **方法论同频（最关键）**：Orford 靠"扒评论、看退货、拆尺寸偏好"做选品——你做过 200 份问卷 + 十几场访谈 + 5 份竞品分析，**同一套"先挖清楚用户要什么，再定义产品"的逻辑**。
4. **成本利润核算**：198000 → 25740 → 13% 的真实账目，正好命中"成本利润核算 + 销售初期预测"。
5. **供应链与供应商接触**：832 平台的选品、资质审核、履约协调，是"供应商体系"的入门级完整链路。
6. **对电子商务是真做过**：832 平台是真实的线上销售平台，不是纸上谈兵——"对电子商务有激情"的最好证明是干过。

## 六、缺口与补救（诚实标注，不虚构）

1. **🔴 家具行业量产经验**：你的项目是课程/个人项目，非量产落地。**诚实讲法**：突出"完整走通从调研到方案的产品链路"和"自有工厂场景下的结构/材料意识"，不假装做过量产。
2. **🟡 认证合规知识（CE / FCC / UL / Prop65 / FSC）**：目前无实操。**投递前动作**：花半天了解这 5 个认证各管什么（安全 / 电磁兼容 / 加州化学物质 / 木材来源），面试被问"你怎么理解跨境合规"时能答上。
3. **🟡 英语读写（跨境刚需）**：CET-4 469 / CET-6 452，分数不算亮眼。**建议**：面试不回避，强调读写能独立完成（扒英文评论、看亚马逊后台英文资料）；如果近期有提升计划可提。
4. **🟡 商务谈判无直接案例**：融水是内部协调。面试话术见下节。
5. **💡 加分动作**：投递前做一份**《WLIVE / DEVAISE 亚马逊爆款评论考古》小报告**——挑 1 个收纳柜或升降桌，扒 50–100 条真实评论 + 差评，列出"用户痛点清单 → 产品改进建议"。这份文档**和 Orford 的选品方法论完全同频**，杀伤力远超简历本身。

## 七、面试高频追问预备（结合 Orford 文化）

- **"你怎么判断一个品值不值得做？"** → 用"市场容量 → 竞争格局 → 差异化机会"三步法，举融水选品或宠芯竞品调研的例子，落到"先挖用户要什么，再定产品"。
- **"你为什么选我们公司 / 了解 Orford 吗？"** → 讲 **WLIVE（收纳）与 DEVAISE（办公家具）双品牌**、自有工厂的"研发—生产—销售"一体化、以及你最认同的**"刨根问底"调研选品**——用你做过 200 份问卷的经历呼应。
- **"成本怎么算？"** → 融水 13% 收益率的真实账目是唯一硬牌，主动摊开讲；补充 Delta"结构 / 材料 / 包装"三个降本维度的理解。
- **"用户体验思维对新品开发有什么用？"** → 这是你反超纯商科候选人的题：**选品逻辑 = 需求验证逻辑**，200 份问卷的方法可以直接迁移到品类调研与评论考古。
- **"你能接受前期在常州总部吗？"** → 明确表态（该岗位公开信息显示前期需 base 常州总部，深圳为电商中心）。
