        ## 调研方法

        1. WebSearch 锁定主营业务 + 团队规模 + 客户名单
        2. 公开招聘 JD 反推岗位画像（薪资 / 工具要求 / 工作内容）
        3. 结合候选人能力做匹配度评估
        4. 产出"同频点 / 缺口 / 面试追问预备"三件套
